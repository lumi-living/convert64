# lineart — png2amiga's baselines (the png2amiga solver's parity references)

png2amiga's renders of [`../../lineart/source.png`](../../lineart/source.png), the references of the png2amiga port's parity tests (`crates/convert64-core/tests/png2amiga_parity.rs`, `crates/convert64-cli/tests/png2amiga_convert.rs`). Since ADR-014 they are not the fixture's gated baseline: that is png2c64's, in [`../../lineart/`](../../lineart/README.md).

## VICE check (#273)

Made by `cargo xtask vice-check` while these were the gated baselines (#273); the check now runs on png2c64's baselines.

- VICE check (`cargo xtask vice-check`): VICE 3.10, `x64sc -default -pal -VICIIextpal -VICIIpalette pepto-pal -VICIIfilter 0 -VICIIsaturation 1000 -VICIIcontrast 1000 -VICIIbrightness 1000 -VICIIgamma 1000 -VICIItint 1000 -sounddev dummy -warp -autostartprgmode 1 +autostart-delay-random -limitcycles 30000000 -autostart baseline.prg -exitscreenshot vice.png` on the display PRG `convert64-formats` builds from this baseline. [vice.png](vice.png) agrees with the baseline on 100.000 % of pixels; 1000 of 1000 cells show only the baseline's colours.

## png2amiga baseline

Generated by `cargo xtask png2amiga renders`; do not edit this section by hand.

- Tool: png2amiga 1.111.2.1247, commit `4a8777653536ac07074a650ee86860347c8755fb` (<https://github.com/tinic/png2amiga>), the reference build ([png2amiga-reference.md](../../../docs/reference/png2amiga-reference.md))
- Mode: hi-res bitmap (Art Studio)
- Command:

  ```sh
  png2amiga source.png baseline.hir --mode c64-hires --c64-palette pepto --c64-metric mse --dither none --gamma 1.5
  ```

- Files: `baseline.art` is the picture png2amiga writes (`.hir`, the same bytes); `baseline.png` is it drawn at 320 × 200 through Pepto. `baseline_match_range.png` adds `--match-range`, `baseline_refine.png` `--cell-refine`.
- png2amiga's SSIMULACRA2 (its own, against its preprocessed input): `baseline` 1.45, `baseline_match_range` 1.41, `baseline_refine` 21.76
