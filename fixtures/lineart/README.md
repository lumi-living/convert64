# lineart — Line art (hi-res bitmap, 2 colours per 8×8 cell)

Black-ink tactical sketch map: contours, stream, dashed track, pine symbols, trench line, unit boxes, north arrow, scale bar.

## What it tests

The only hi-res fixture: pure two-colour output, thin strokes crossing cell boundaries, anti-aliased source edges that must threshold cleanly. Note: the generator added a letter “N” at the north arrow despite the prompt; it is left in as realistic input.

## Rights

Generated by Jaakko Haaparanta with Nano Banana 2 (Google) from a text prompt written for this project; no third-party source material. Licensed under the repository's MIT licence for use as a test fixture.

## Technical

- `source.png`: 1024×637, 8-bit sRGB, no alpha, metadata stripped on import.
- Supersample factor relative to the 320×200 C64 grid: **3.20× horizontally, 3.19× vertically** (the compositor's default is 4×; anything ≥ 3× is fine for sub-pixel tests).
- Added 2026-10-11 for epic E3 (#3).
