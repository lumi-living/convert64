# terrain — Terrain tile sheet (charset / tile modes)

Top-down 20×12 tile sheet for an Eastern Karelia 1941 map: pine, birch, swamp, snow, ice, road, trench, sandbags, rocks, timber, edges.

## What it tests

Charset budget: 20×12 tiles × 2×2 chars = 960 candidate characters against the 256 limit, forcing real merging; per-tile colour discipline (bg/MC1/MC2 global + one 0–7 colour per char); seamless-tile edges. Deliberately more detailed than a shippable C64 tileset — it is a stress fixture, not game art.

## Technical

- `source.png`: 1024×637, 8-bit sRGB, no alpha, metadata stripped on import.
- Supersample factor relative to the 320×200 C64 grid: **3.20× horizontally, 3.19× vertically** (the compositor's default is 4×; anything ≥ 3× is fine for sub-pixel tests).
