# portrait — Portrait (multicolor bitmap, skin tones)

A Finnish infantryman, 1942, oil-painting style, warm/cool split lighting on a flat olive background.

## What it tests

Same-luminance dither pairs on skin (Orange+Purple, Light Red+Green, Red+Dark Grey), warm-vs-cool shadow split, hair/skin/background cell clashes, fine knit texture next to flat cloth. Also the source for the M2 overlay-sprite portrait test.
